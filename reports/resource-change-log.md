# 昨日资源变化记录

文案和随机句子配置：`data/resource_log.json`。`sources` 内每项的 `descriptions.en` 和 `descriptions.zh-CN` 按相同下标对应，可继续追加句子。事件选项使用 `data/events.json` 中对应选项的 `summaryLine`，译文位于 `locales/*.json`；也可在 `sources` 内添加 `event.事件ID.选项ID`，为该选项设置多条随机句子。

每次结算记录实际差值，先计算库存上限、剩余量和健康下限，再记录。句子变体在结算时选择并保存，不消耗事件 RNG。昨日条目只在日终冻结，第二天晨间发电属于新一天。旧存档无这些字段时保留原记录，不伪造历史。

| 变化来源 | 涉及数值与规则位置 |
| --- | --- |
| 晨间太阳能发电 | 电力实际入库量、每日发电量；受积尘、追踪上限、设备故障和电池上限影响；TurnEngine |
| 维生运行 | 通常 −3 电力，叠加额外维生耗电；不足时仅扣剩余电力；TurnEngine |
| 舱内照明 | 日终开灯且有电时 −1 电力；TurnEngine |
| 日常进食 | 每日 −2 食物，不足时仅扣剩余库存；TurnEngine |
| 缺粮 | 健康 −12，最低 0；TurnEngine |
| 维生断电 | 健康 −15，最低 0；连续故障次数增加或恢复后归零；TurnEngine |
| 数据确认 | 待确认数据减少、已确认数据增加；TurnEngine |
| 作物照料与收获 | 耗电、作物进度、食物实际入库；成本/产量受事件影响；ActionRules |
| 科研、机器人、监测仪 | 耗电和本地数据增加；ActionRules |
| 发送数据 | 耗电、本地数据减少、待确认数据增加；ActionRules |
| 清洁与维修 | 耗电、发电/追踪能力恢复；ActionRules |
| 休整 | 耗电、健康恢复，受健康上限限制；ActionRules |
| 备用电池 | 最多 +6 电力，受 12 电力上限限制；GameModel |
| 所有事件选项 | 选项耗电、健康/备件成本、食物/健康/本地数据增减、备件补充、作物重置、数据转移、狭小空间惩罚；DailyEventRules |
| 事件持续影响 | 发电/追踪上限、额外维生耗电、照料成本、收获产量、实验室恢复日期、传输上限；DailyEventRules |

开关灯、积尘、屏蔽和工具消耗等布尔/状态变化继续使用原有叙事；后续实际产生数值变化时记入对应结算条目。初始化库存不属于当天收入，不重复记账。

显示：昨日记录保留原有故事总结，并追加逐项说明和实际变化。电力使用带正负号的小电池图标，每个表示 1 E，倾斜 20°；其他资源显示名称和差值。
