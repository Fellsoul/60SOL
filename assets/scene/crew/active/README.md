# Active crew action atlas

`action-atlas-v1.png` was generated with the built-in imagegen tool using the existing `astronaut_a/seated.png` and `outpost_baseMain.png` as character/style references. The original assets were not overwritten. The square RGBA atlas uses four equal cells: top-left indoor idle; top-right walking key pose; bottom-left supported kneeling work; bottom-right closed-helmet EVA suit with gloves, boots and backpack.

The atlas is used only in the action-status card. The walking cell is a candidate pose, not an animated gait or an approved world-space sprite. It is not enabled on room routes. EVA artwork was visually checked as an illustration; it does not certify a suit. `data/movement.json` explicitly leaves camera calibration, routes and visible exterior walking disabled pending scene/asset validation.

## Final generation prompt

Use case: stylized-concept. Generate ONE production game sprite atlas, a square image with EXACTLY a 2 by 2 grid of four equal square cells, transparent background. Input 1 is the character identity/style reference; input 2 is habitat illustration style reference, NOT a background to reproduce. Match the warm hand-painted colored-pencil/comic shading, strong uneven charcoal outlines, muted cream/tan fabric, orange trim and gray joint padding of this game. Same adult astronaut with shoulder-length black hair throughout. Cell TOP LEFT: full body indoor standing idle, three-quarter facing left, both boots grounded, arms relaxed. Cell TOP RIGHT: full body indoor deliberate grounded walking key pose facing left, one boot planted, no jumping, no floating. Cell BOTTOM LEFT: full body kneeling work pose facing left, hand operating a small handheld instrument; plausible ground support. Cell BOTTOM RIGHT: full body standing surface EVA astronaut, enclosed pressure suit, visibly CLOSED sealed visor helmet, gloves, boots, life-support backpack; no exposed skin, pressure hoses secure. This is a fictional generic EVA ensemble, not a certified design. All four figures isolated, no overlap between cells, same proportions and clothing palette, consistent nominal scale, centered in each cell with a generous 12% transparent margin, lowest foot around 90% of cell height. No scenery, no chairs, no furniture, no panels, no decorative borders or grid lines, no captions, no words, no watermark. The atlas will be used for a compact action-status illustration, not as evidence of validated scene walking.
