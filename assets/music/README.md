# 背景音乐

配置位于 `data/presentation.json` 的 `music`：

- 主菜单：`NASA LLO.mp3` 循环播放。进入游戏淡出，返回菜单淡入。
- 游戏内：`14Sol.mp3` → 间隔 2000ms → `3Souols.mp3` → 间隔 2000ms → 重复。
- 黑幕覆盖场景时音乐淡出并暂停；场景从黑幕中显现时从原播放位置淡入。切日不重置曲目或播放时间；曲间等待也会暂停并保留剩余时间。
- 音量使用设置中的音量控制。浏览器禁止自动播放时，在首次点击或键盘交互后重试。
- 播放位置保存在当前页面会话中；刷新页面后从首曲开始，不写入游戏存档。

现有过场环境音/剧情录音仍由 `ambient` 和 `recaps` 配置独立控制。
