# PNG 素材制作与导入清单

终端右侧电池槽使用 `assets/terminal_battery_slot.png`（1536 × 1024），保留原图电线并随终端移动。三节电池各 4 灯，共表示 12 E。`src/views/BatterySlotView.js` 按原图灯带坐标叠加局部灰度图层，实时显示缺电状态；原始素材不需导出 13 个电量版本。更换构图时需要同步调整该文件中的灯带坐标。

游戏终端框使用你提供的 `scene/interior/outpost_console.png`（1672 × 941）。宽度固定为视口的 60%，底部收起露出 10%，展开露出 80%。图片屏幕内的文字区、滚动区与按钮由 HTML 叠加，位置见 `styles/terminal.css` 的 `.is-console .terminal-shell`。点击外侧场景或关闭按钮收起，Esc 同样可用；主菜单的准备与设置仍使用左侧面板。

这里是供你自己生成、抠图并放入目录的素材要求。项目不再使用程序拼成的场景，也没有替你生成 PNG。文件夹已建立。

**先做一张完整的室内构图参考，再基于同一张参考拆图、编辑状态。** 不要独立生成每一张状态图，否则镜头、窗框、人物大小和物件位置容易变化。

表格中的路径通常相对于 `assets/scene/`；货架的两个完整画布素材位于 `assets/` 根目录。完整路径见 `assets/PNG_FILES.txt`。文件名须与配置一致；放入后刷新页面读取。

游玩时的五种工具已预留完整画布透明图层，具体路径见 [工具图片槽位说明](scene/tools/README.md)。

## 第二批：5 张，接通天气与植物状态

| 文件 | 张数 | 内容要求 |
| --- | --- | --- |
| `exterior/main/sandstorm/far.png`、`near.png` | 2 | 主窗的远、近两张独立沙尘纹理。只画沙尘，不包含地形、设备或窗框；透明背景，左右边缘可无缝平铺。 |
| `exterior/right/sandstorm/far.png`、`near.png` | 2 | 右窗的远、近两张沙尘纹理；与主窗保持一致风向及颜色，左右边缘可无缝平铺。 |
| `greenhouse/plants/growing.png` | 1 | 幼苗与成熟之间的生长阶段，沿用相同画布、透明边距和根部锚点。 |

沙尘不再切换帧图；背景始终显示 `clear.png`。主窗按“外景 → 积尘 → 远/近沙尘 → outpost-main”叠放，右窗整组在主窗组上方，按“右侧外景 → 温室/植物 → 远/近沙尘 → outpost-right”叠放。右侧外景的非透明区域会遮住下方主窗沙尘；两侧仍保留各自的窗口裁剪区域。每层将同一纹理并排复制两份，通过线性 transform 连续向左移动一张纹理的宽度后循环。浏览器按刷新率插值，不设低帧率计时器。

沙尘纹理是局部小图，**不要使用包含整幅场景透明边距的画布**。主窗纹理建议约 769 × 339，右窗约 418 × 753（按现有 1672 × 941 基底）；按窗口区域拉伸填满，尺寸比例可依美术调整。左右两端的纹理和透明度要衔接，避免循环时出现接缝；远景用细薄沙雾，近景用更明显的沙尘条纹。

`data/scene_layout.json` 中 `viewport` 的 x/y/width/height 是画布百分比，固定窗口裁剪区域，室内窗框负责最终遮挡。当前 `motion.speed` 为 900 原始画布像素/秒，实际速度为 `speed / depth`：远景 depth=3（300 像素/秒），近景 depth=1（900 像素/秒）。`direction` 可设 `left` 或 `right`。同侧近景速度是远景的 3 倍；视口缩放后保持相同循环周期。

四层沙尘的初始不透明度 `opacity` 均为 0.5（50%）。`motion.variation` 控制随机呼吸：`opacityMin/Max` 为 0.3～0.7，`scaleMin/Max` 为 1.04～1.16，`durationMinMs/MaxMs` 为 3500～7000 毫秒，`driftPercent` 为上下 1% 的漂移幅度。每个图层、每个呼吸周期独立抽取新参数，并平滑回到起点衔接下一次呼吸。缩放和漂移作用于纹理内部，窗口裁剪区域保持固定。

晴天隐藏四层；减少动画时保持 50% 不透明度静止显示；切到后台时位移、呼吸和缩放一起暂停，返回继续。缺少某张纹理时只隐藏该层，其他图层继续显示。旧 `frame_*.png` 已不再加载，可自行归档。

种植槽为空时直接隐藏植物层，因此不需要 `seed.png`。成熟状态保留到下一次照料开始新一批。

## 尺寸、对齐和遮挡

- **静态场景 PNG 都与 `interior/outpost_baseMain.png` 的原始宽高一致**，人物、工具、植物、右侧外景和光效使用完整画布；四张沙尘纹理例外，使用上文的局部平铺图。网页优先读取 Main 基底实际尺寸，缺少基底时使用配置中的 1672 × 940。
- 两张 outpost 基底应当互补：Main 保留主窗和左侧结构，Right 保留右窗和右侧结构。分界放在两个窗口之间的实心墙体上，保持原像素位置，避免接缝留白。旧 `outpost_base.png` 不再参与加载。
- 完整画布叠层不要裁掉透明边缘。室内窗洞必须带 alpha 通道；棋盘格不能画进图里。
- 人物、植物、工具在完整画布内直接画到最终位置，其余区域透明。状态切换时物件位置在图片中固定，不裁成局部小图，不自动裁剪透明边缘。
- 静态场景图层使用 `inset: 0`、`width: 100%`、`height: 100%`。四个沙尘图层使用固定窗口区域，仅内部纹理位移。整个场景统一缩放以适配屏幕。
- 座椅若在室内基底中，人物应是坐到空椅上的透明图。桌子单独导出为 `interior/outpost_table.png`，在人物前方显示；基底中不要再画同一张桌子。桌上工具由更高的工具层显示。
- 灯光叠层不画第二套房间；否则会覆盖人物和工具。若只能生成“亮灯整张照片”和“熄灯整张照片”，可以改为切换两张室内图，并禁用单独灯光层，避免双重照明。

## 统一生成说明

建议给每张图附上这段约束，再追加上表对应的具体内容：

> 固定镜头的火星前哨站叙事生存游戏素材。使用所提供的室内构图作为唯一透视和光源参考，保持一致画风、镜头、物体比例和位置。画面不包含 UI、字幕、数字、进度条、水印。此图只包含指定图层，不把其他独立图层画进去。要求透明的部分输出真实 alpha 通道 PNG。

状态图应引用对应原图进行局部编辑；沙尘纹理参考场景画风与色调，只包含透明沙尘。

## 放入后如何读取

1. 按 `PNG_FILES.txt` 的路径放入文件，名称与扩展名完全一致。
2. 用本地 HTTP 服务打开页面，刷新。已存在的 PNG 会加载，缺图层保持空缺。
3. 在 `data/scene_layout.json` 中调整每层 `zIndex` 和状态对应的 `src`。静态图片靠完整画布对齐；沙尘窗口区域使用 `viewport`。
4. 用 `?debug` 打开页面可查看整幅图层边框；图片内的对齐由素材自身保证。
5. 沙尘速度修改 `motion.speed`，远近距离修改 `motion.depth`（越大越慢）；不再使用 `sequence` 或 `fps`。

黑幕、侧栏滑入、终端打字机和选择按钮由 HTML/CSS/JS 实现，不需要为这些界面生成 PNG。
